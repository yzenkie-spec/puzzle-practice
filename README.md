# Puzzle Practice

A home-made iPad practice app for Grade 3 gifted screening practice.

- The app is a plain website: `index.html` plus the `js/` folder. There is nothing to build.
- Saving a change to this repo (`main` branch) runs the tests (GitHub Actions) and publishes the site (Netlify).
- Tests live in `tests/`. Run them with `python3 tests/invariants.py` and `python3 tests/flows.py`.
